# Кастомизация

Всё, что можно менять — это:
1. **Шаблоны языков.** Вкладка «Другое» → выбрать язык → редактировать.
   Формат: `### Название` + код.
2. **Темы.** Вкладка «Другое» → «Создать свою».
3. **Свои языки.** Файл `.py` в `plugins/` + кнопка «Язык из файла».

Файл `config.json` рядом с .exe хранит все изменения.
